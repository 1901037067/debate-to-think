# 辩思 · Debate to Think

和 AI 逐轮辩论，结束后回看自己的论证，再练习把立场说得更清楚。

**当前版本：v0.3.1 试用版。** 保留按开篇、追问、交锋与收束调整表达的规则，补充了当前子结论的举证边界：学习需要、付费意愿与使用效果分别判断。补丁尚待真实复测，自然感与训练效果仍需用户试用验证。

## 它怎么陪你练习

选定辩题和立场后，AI 每轮围绕一个关键分歧追问，等待你回应。你可以随时请求提示、修改立场、换边或结束。

结束后，AI 引用双方实际说过的话，分析论证扎实的地方、需要修补的问题与尚未解决的分歧，并检查自己的反驳有没有问题。你还可以继续练习：替对方提出最强理由，再重写自己的立场。

修改观点是训练的一部分。AI 承认你的有效回应，也会在自身理由站不住脚时修正。复盘不是独立裁判的结论；事实问题仍需要可靠证据。

对于“该不该使用”这类含混表述，AI 会先厘清你指的是允许选择、通常推荐还是人人必须；交锋时保留你的限定条件，区分研究发现、类推与假设。思想实验中已接受的能力条件，也不能在反驳时被偷偷改掉。

交锋时，AI 围绕你刚说的具体意思推进，不必每轮把整套论证重新分析一遍。追问可以短，开篇和收束可以展开；你也可以要求更像现场的接话，或让它把当前推理讲详细。事实核实与关键纠错仍在当轮完成，完整分析可在复盘时展开。

## 开始使用

仓库根目录就是完整的 skill 文件夹，入口为 [SKILL.md](SKILL.md)。

在支持读取本地文件的 AI 编程助手中，可以先不安装，直接输入：

```text
请读取本地 debate-to-think/SKILL.md，按其中的规则陪我进行一次辩论训练。
辩题：大学课程是否应该允许学生用 AI 完成作业？
我的立场：应该允许，但要披露使用方式。
我的理由：合理使用工具也是学习能力的一部分。
```

将路径替换为你实际下载的位置。此方式要求助手能读取本地文件，复盘时也要能读取 skill 中链接的参考文件。

要作为 Codex skill 使用，将整个文件夹复制到 `$CODEX_HOME/skills/debate-to-think`；未设置 `CODEX_HOME` 时使用 `~/.codex/skills/debate-to-think`。保留 `agents` 和 `references` 子目录。让宿主重新加载 skills 后调用：

```text
$debate-to-think 我想练习思考，先帮我选一个辩题。
```

也可以带上自己的主张直接开始：

```text
$debate-to-think 辩题：远程办公是否应该成为知识工作者的默认方式？
我支持，因为它减少通勤，也让人更能安排自己的时间。
普通强度，先练四轮，最后做逻辑复盘。
```

这些是启动提示示例，不是真实对练记录。普通聊天产品能否发现或加载 skill，取决于宿主能力；本仓库不提供独立应用或模型服务。

## 训练中的常用说法

| 你说 | AI 应该怎么做 |
| --- | --- |
| 提示一下，我卡住了 | 给一个思考抓手，再等你组织回应 |
| 暂停 | 停止追问，保留当前分歧 |
| 继续 | 接着未解决的问题讨论 |
| 我想修改立场 | 以新立场继续，记住修改发生过 |
| 换边 | 交换立场，让你尝试另一方的最强论证 |
| 先小结一下，之后继续 | 收束当前争点，不自动结束训练 |
| 说得更像现场一点／把推理讲详细 | 调整表达与展开程度，保留原有条件和证据标准 |
| 结束，开始复盘 | 立即结束交锋，按已有材料分析 |
| 只给报告，不继续练习 | 完成复盘，不强制追加作业 |

默认普通强度、约四轮一个短练习；可要求更温和、更严格或调整轮数。严格模式增加追问深度，不降低证据标准，也不允许羞辱。
