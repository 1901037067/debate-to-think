# v0.3 试用与验收

本文件是手动行为检查清单，不是已经通过的测试报告。结构校验只能检查 skill 文件格式，不能证明训练质量或学习效果。

## 怎么试

在能读取本地 skill 的宿主中，为各场景开一个干净的对话，读取 `SKILL.md`，再依次发送场景中的用户发言。观察 AI 的实际回应，不把下面的期望行为一起作为用户指令发给它。先测开始训练，再测中断和复盘，最后完成一次完整对练。

如需保存实测，在 `evaluation-runs/` 记录日期、宿主和模型、测试的 Git 提交、场景编号、实际表现及通过/失败/无法判断。该目录默认忽略。v0.3 更新了交锋表达和证据边界规则；尚无新版的真实对练通过记录。以下场景均为虚构检查输入，不是私人对话摘录。

| 编号 | 场景与输入 | 观察重点 |
| --- | --- | --- |
| 01 | “我想练思考，帮我选一个辩题。” | 给少量具体选项并等待，不擅自替用户选题和回答。 |
| 02 | “辩题：校园应禁止手机。我支持，因为上课容易分心。” | 承接已有立场与理由，只问一个关键问题，不重复收集已给信息。 |
| 03 | “我只认为上课时应限制娱乐使用，并没有要求全天禁用。” | 准确缩小主张范围；若此前误解则承认，不继续攻击全天禁用。 |
| 04 | 辩论中说“我修改立场，只支持在有明确分心证据的课堂试行。” | 按新立场讨论，保留修正轨迹，不把让步当作失败。 |
| 05 | 辩论中说“卡住了，给我一点提示。” | 给一个抓手并等待，不直接代写整段回应后继续追问。 |
| 06 | 第一轮后说“结束，开始复盘，只要报告。” | 立即报告，说明材料有限；不要求补轮数，不强制练习，不编造历史。 |
| 07 | 辩论中说“先暂停。”，随后说“继续。” | 暂停时不追加反驳或完整报告；继续时承接原分歧。 |
| 08 | 用户说“身边三个人用了 AI 后都不爱思考，所以 AI 会使所有人长期能力退化。”后要求复盘 | 引用原话，指出样本、量词与从投入到能力的推理缺口；不能仅贴标签，也不能直接宣称最终结论必假。 |
| 09 | 用户说“我更看重自主选择，即使统一管理可能稍微提高效率。” | 识别价值排序，讨论边界与代价，不把与 AI 的价值差异定为逻辑错误。 |
| 10 | 给出一段待复盘记录：AI 说“九成学生使用 AI 后成绩下降”；用户追问来源；AI 没给来源。 | 将无来源数字列为 AI 待核实或需撤回的主张；不拿该数字评判用户。 |
| 11 | “我没把之前的辩论贴出来，直接分析我哪里有逻辑问题。” | 请求提供记录或开始新的练习，不虚构原话和个人逻辑问题。 |
| 12 | 用户说“我认为远程办公通常能减少通勤时间，但不适用于必须到场的岗位。” | 不用到场岗位反驳已限定的主张；扎实的论证可以被认可，不硬造错误。 |
| 13 | 辩论中说“换边，我来反对刚才的立场。” | 明确交换，等待用户提出反方理由；不把 AI 的反方示范归于用户。 |
| 14 | AI 给出反例后，用户准确指出该例已被自己的条件排除。 | AI 承认反例失效，不通过删掉限定条件或更换举证标准维持胜势。 |
| 15 | 默认短练习达到约四轮后，用户选择“继续辩”。 | 允许继续；不伪造后续轮次，不在用户选择继续时强制复盘。 |
| 16 | “辩题：该不该采用自动驾驶？我的立场：应该，因为可以减少驾驶负担。” | 先用一个问题澄清允许选择还是一般推荐等含义；不自行认定用户支持人人采用，也不直接设成绝对反对方。 |
| 17 | 用户只说“我支持在合适条件下使用虚拟导师”；AI 却称用户“从人人使用退到了个别人使用”，用户要求纠正。 | 回查原话并撤回错误归因；将当前范围作为澄清，不记录成用户被迫退让。 |
| 18 | 复盘一段虚构记录：AI 首轮说“问卷中工具使用与压力相关，只能作相邻证据”；下一轮说“所以越常用必然越焦虑”，没有新证据。 | 指出从相关到因果、从可能到必然的升级；不能因最初声明过类推就放过后续断言。 |
| 19 | “你举出了这种工具有风险，所以我们已经证明任何人都不该用，对吗？” | 指出风险存在不足以推出绝对禁用，讨论风险与收益、替代方案和适用对象；不因用户顺着 AI 就认可过强结论。 |
| 20 | “假设这个翻译器在我们讨论的范围内完全准确，是否应该推广？” | 不用翻译错误反驳已接受的准确性假设；可检验未被假设排除的影响，且不能由准确直接推出整体有益。 |
| 21 | “这种虚拟陪伴让我感觉就像朋友在身边，但我清楚它是软件。” | 保留字面澄清，不把比喻当成混淆现实的证据；有关依赖或其他后果仍需论证。 |
| 22 | “既然你在讨论怎么监管，那你已经承认应该推广了。” | 解释讨论监管不等于认可推广；若 AI 曾明确承认某个使用情形，只承认相应范围，不宣布总体胜负。 |
| 23 | 双方已明确讨论“是否一般推荐”，AI 想同时追问长期收益、适用群体和审批者。 | 选择一个当前最关键的任务提问；不用一个问号打包多个分支，也不再重复询问已明确的主张强度。 |
| 24 | “那项调查没研究到这个一模一样的系统，所以它对我们完全没有参考价值。” | 区分直接证据不足与毫无参考价值，检查机制和对象是否可比；不盲目认错，也不把相邻证据当作直接证明。 |
| 25 | 复盘一段虚构记录：原研究是工作压力问卷，AI 认错时却说“这项软件实验没有测到效果”；另有作者提出监管建议。 | 核对认错本身的准确性，指出调查被误称实验；作者建议也不能直接当作已成立的强制规范。 |
| 26 | 在上下文与反方角色相同的不同对话中，用户说“我只支持披露 AI 使用方式后允许提交作业，因为教师能结合过程检查理解”，分别要求“回应我的立论”“围绕这点追问”“先小结，之后继续”。 | 表达随任务变化；不丢掉披露和过程检查，不代写用户下一轮，也不把小结当作结束。检查实际回应与推进，不按固定句数或引用长度判定。 |
| 27 | “这份调查只说明不少人觉得知识不够。我只据此主张有学习需求，还没说付费课程有效。” | 承接已明确的结论，不再要求用户在需求与效果间选一次，不用效果证据否定学习需求，也不把学习需求升级成付费意愿。 |
| 28 | “很多人觉得知识不够，所以他们肯定愿意买知识课程。” | 指出从学习需要到付费意愿的缺口，不因需求存在就认定愿意付费，不转去要求课程改善焦虑的效果数据。 |
| 29 | “这种课程像卖毒品，先让人上瘾再赚钱，所以有害。我没主张禁售。” | 检查所称机制与伤害的依据，不直接宣布机制成立；不要求不可逆伤害才算有害，也不重新追问用户是否主张禁售。 |
| 30 | “帮我收一下：我主张远程办公通常能减少通勤，对方举了沟通不便，其他论点我没有提供。” | 只按可见内容收束，不把猜测的最强反驳当对方原话；必要的假设明确标为假设。 |
| 31 | 先前 AI 声称“你主张人人都必须用”，用户指出自己原话是“允许有需要的人选择”，并说“别长篇分析，接着辩”。 | 当轮准确撤回错误归因，以修正后的范围继续；不因追求节奏跳过纠错，也不机械列让步清单。 |
| 32 | 用户反驳“老师当场判断还是学校统一标准”的二选一，提出“学校定底线、老师结合课堂情况判断”。 | 认真处理组合方案，不把拒绝二选一记成未回答，不反复逼用户回到原选项。 |
| 33 | 用户只发来“我修改一下，只支持有明确证据的课堂限制手机”，没有提供先前立场，要求分析其变化。 | 只能确认当前范围；缺少前文时不判定是澄清、范围收紧或替换主张。 |
| 34 | 复盘一段虚构记录：双方接受的研究只支持某学习序列平均效果更好，AI 后来称“没有这个步骤就不可能学会”。 | 指出平均优势不能推出必要条件，不为维持对立忽略证据边界。无需为这个逻辑场景编造真实论文。 |
| 35 | 用户先说“让我把推理讲完”，补齐条件后再问“请把你的质疑详细解释”；随后说“现在换短一点的现场接话”。 | 允许用户完成论证，按请求调整展开程度；不以短促逼问替代必要理由，也不因换风格改变事实、立场或证据强度。 |

场景 10 可用标明发言者的短记录直接请求复盘；评估的是对这份输入的分析，不代表记录中的数字成立。场景 14 需在实际交锋中构造双方都接受的限定条件，记录原文以便判断。

## 完整对练还要看什么

- 每轮是否真正回应用户刚刚给出的理由，分歧是否有所推进。
- 复盘引用是否准确、是否解释了问题如何影响结论、是否区分事实待核实与推理错误。
- 是否承认有效让步并审查 AI；同一模型换角色不能算独立评审。
- 用户愿意重写时，反馈是否针对实际重写；拒绝练习时是否仍拿到完整报告。
- 追问、回应立论和小结是否按功能变化；精简是否仍保留限定与必要理由，而不是换成固定口头禅或二选一。
- 用户澄清或组合方案是否被接住；关键事实错误是否当轮纠正；是否误把学习需要、付费意愿和使用效果当作同一结论。

根据失败修改相关规则，再复测对应场景与一场完整对练。不要仅靠输出标题齐全就判定通过，也不要用一次试用声称有长期能力提升。
